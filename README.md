**Аудиоплеер** - это музыкальный плеер, позволяющий по очереди проигрывать музыкальные треки или перелистывать их с помощью кнопок. Каждому музыкальному треку соответствует определённое изображение, название и автор. Отображается продолжительность аудиотрека и его текущее время проигрывания.

- есть кнопка Play/Pause, при клике по которой можно запустить или остановить проигрывание аудиотрека
- при кликах по кнопкам "Вперёд" и "Назад" переключается проигрываемый аудиотрек
- аудиотреки пролистываются по кругу
- при смене аудиотрека меняется изображение - обложка аудиотрека
- прогресс-бар отображает прогресс проигрывания текущего аудиотрека
