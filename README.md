**Виселица** — классическая игра в слова, где нужно найти правильный ответ, угадывая буквы по одной. Можно использовать как виртуальную, так и физическую клавиатуру. Все необходимые элементы генерируются с помощью JavaScript.
- все необходимые элементы генерируются с помощью JavaScript
- можно играть, используя виртуальную клавиатуру
- можно играть, используя физическую клавиатуру
- если буква правильная, она появляется вместо соответствующего подчеркивания
- если буква неверна к виселице добавляется часть тела
